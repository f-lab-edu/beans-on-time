# Beans on Time

> **Fresh beans, right on schedule.**

Beans on Time은 고객이 선택한 커피 원두를 원하는 주기에 맞춰 배송하는 정기구독 백엔드 서비스입니다.

## Overview

고객은 원두 상품, 수량, 배송 주기와 배송 정보를 설정하여 구독을 시작할 수 있습니다.

시스템은 구독 계약을 기반으로 각 배송 회차의 청구와 결제를 처리하고, 결제가 완료되면 정기배송 주문을 생성합니다.

```text
구독 생성
→ 배송 회차 도래
→ 청구 및 결제
→ 정기배송 주문 생성
→ 출고 요청
```

고객은 자신의 일정과 소비 패턴에 따라 다음 배송을 건너뛰거나 구독을 일시 정지하고 다시 시작할 수 있습니다.

## Project Focus

이 프로젝트는 단순한 구독 CRUD 구현보다 다음 문제를 다루는 데 중점을 둡니다.

* 구독 계약과 개별 배송 회차의 분리
* 회차별 반복 청구와 주문 생성
* 중복 청구·결제·주문 방지
* 결제 실패에 대한 재시도
* 처리 도중 발생한 장애의 복구
* 구독 변경사항의 적용 시점 관리

## Architecture

Beans on Time은 DDD와 헥사고날 아키텍처를 기반으로 설계합니다.

도메인 규칙을 애플리케이션 프레임워크, 데이터베이스 및 외부 시스템으로부터 분리하고, 구독·결제·주문 처리 과정의 책임과 경계를 명확하게 정의하는 것을 목표로 합니다.

- Spring Boot 4.1
